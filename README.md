  ## 03 / Shipped Work

  ### Task Manager 2.0 (https://github.com/tylerdobson/Task-Manager)

  Course project · Next.js and React

  An accessible personal task manager with filtering, live statistics, defensive
  browser persistence, responsive controls, and automated behavior tests.

  Evidence: 4 integration tests, production-build verification, accessibility
  documentation, and a current application screenshot.

  ### Career Path Command Center
  (https://github.com/tylerdobson/career-command-center)

  Live system · Full-stack application

  A career-evidence tracker built with Next.js, TypeScript, Supabase, PostgreSQL,
  Zod, Vitest, and Playwright. The public demonstration uses seed data instead of
  private career records.

  View case study
  (https://tylerdobson.github.io/projects/career-path-command-center/) ·
  Open live demo (https://career-path-command-center.vercel.app/)

  ### Decision Intelligence Lab
  (https://github.com/tylerdobson/decision-intelligence-lab)

  Case study · Analytics and decision support

  A Python and Streamlit environment for exploring KPIs, forecast ranges, scenario
  inputs, exports, and recommendation-style decision support using modeled data.

  View case study (https://tylerdobson.github.io/projects/retail-kpi/)

  ### Spotify Analytics Dashboard
  (https://github.com/tylerdobson/spotify-analytics-dashboard)

  Case study · API and analytics workflow

  A credential-aware Streamlit dashboard with Spotify API boundaries, SQLite
  persistence, interactive visualizations, and a deterministic demonstration mode.

  View case study (https://tylerdobson.github.io/projects/spotify-analysis/)

  ### Tableau Sales Forecasting Dashboard
  (https://github.com/tylerdobson/tableau-sales-forecasting-dashboard)

  Case study · Business intelligence

  A static Tableau case study covering sales performance, profitability, discount
  analysis, and directional forecasting with clearly documented data limitations.
